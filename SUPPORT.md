# Support

The right support route depends on the project and the kind of question.

## Where to get help

- **Understand a project:** Start with that repository's README, setup instructions and documented limitations.
- **Report a reproducible bug:** Open an issue in the relevant repository and use the available bug-report form. Include steps, expected behaviour and actual behaviour, but remove secrets and personal data.
- **Suggest an improvement:** Use the feature-request form or the repository's discussions when enabled.
- **Private, client-specific or business enquiries:** Visit [the EllowDigital website](https://ellowdigital.netlify.app/) or email [ellowdigitalindia@gmail.com](mailto:ellowdigitalindia@gmail.com).
- **Security issue:** Follow [SECURITY.md](SECURITY.md) and report it privately.

## Please do not post

Never include passwords, API keys, access tokens, private configuration files, customer lists, financial records, patient data or confidential client communications in public issues, discussions or pull requests.

## Support expectations

Support and maintenance availability varies by repository, service agreement, deployment and project status. Opening an issue does not create a service-level agreement or guarantee a particular response or fix date. For a client project, use the contact and escalation path agreed with that client.

When reporting a technical issue, provide a minimal reproducible example and state the affected project version, operating system, browser or runtime where relevant.
