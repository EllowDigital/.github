## Who we are

EllowDigital is an independent digital engineering studio focused on practical software, clear user experiences and dependable delivery. We work across public-facing websites, business applications and operational tools—with an emphasis on solving the actual problem rather than adding complexity for its own sake.

## How we approach engineering

- **Purpose before complexity.** Start with the user, the workflow and the outcome.
- **Clarity and usability.** Make interfaces responsive, understandable and accessible.
- **Security and privacy.** Keep credentials server-side, minimise sensitive data and verify access controls.
- **Maintainability.** Prefer clear structure, useful documentation and focused changes.
- **Reviewable delivery.** Work in small increments and use development branches and pull requests before release.

## Technology

We select tools to fit the problem. Across our projects, the stack includes technologies such as React, TypeScript, Vite, React Native/Expo, Python, Flask, SQL databases and serverless hosting. Each repository's README and dependency files are the authoritative source for its actual stack.
